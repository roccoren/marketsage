# Getting Started

This document describes how to install and start using StockScan for stock analysis and backtesting.

## Installation

```bash
git clone https://github.com/yourusername/stockscan.git
cd stockscan
pip install -e .
```

## Basic Usage

### Running Backtests

```bash
python run_backtest.py backtest --strategy macd --exchange NYSE --symbol AAPL
```

Refer to the example code in the `examples` directory.
