# 股票预测系统算法与参数分析

根据对代码库的全面分析，我现在可以详细解释该系统在预测股票时采用的算法和参数。

## 1. 核心预测算法

该系统主要采用了多种技术指标和机器学习模型来预测股票价格和生成交易信号。

### 1.1 基础预测方法（main.py）

在`main.py`中，系统使用了一个基础的预测函数`predict_future_price`，该函数基于以下技术指标进行预测：

1. **移动平均线**：计算5日和20日移动平均线
2. **动量指标**：计算5日动量变化
3. **波动率**：基于历史收益率计算
4. **趋势强度**：基于短期与长期移动平均线的比较
5. **RSI指标**：基于14天相对强弱指数

预测价格的计算公式：
```python
trend_factor = 0.001 * np.sign(trend_strength)
momentum_factor = momentum * 0.0001
volatility_factor = volatility * 0.1
rsi_factor = (50 - rsi) * 0.0001  # RSI极值时的反向效应
predicted_change = (trend_factor + momentum_factor + rsi_factor) * days
predicted_price = base_price * (1 + predicted_change)
```

### 1.2 高级预测模型（forecasting.py）

在`forecasting.py`中，系统实现了更复杂的预测模型：

1. **LightGBM模型**：使用梯度提升决策树算法，具有以下默认参数：
   - 目标函数：回归（regression）
   - 评估指标：均方根误差（RMSE）
   - 提升类型：梯度提升决策树（GBDT）
   - 叶节点数：31
   - 学习率：0.05
   - 特征抽样比例：0.9
   - 树的数量：100

2. **集成模型**：整合多个基础模型的预测结果，使用动态权重分配：
   - 根据各模型在验证集上的表现动态调整权重
   - 使用时间序列交叉验证（TimeSeriesSplit）评估模型性能
   - 支持多种误差指标：RMSE、MAE、MAPE

3. **特征工程**：为预测模型生成大量技术指标特征：
   - 价格统计特征：移动平均线、标准差、最大/最小值
   - 收益率特征：标准差、偏度
   - 成交量特征：移动平均线、标准差
   - 动量和波动率指标
   - 技术指标：RSI、MACD、布林带
   - 价格与成交量关系指标

## 2. 交易信号生成

系统基于预测结果生成交易信号，主要在两个地方实现：

### 2.1 基础信号生成（main.py）

在`analyze_predictions`函数中：

1. **信号阈值**：基本阈值为0.5，但会根据市场条件调整：
   - 高波动率时（>0.4）提高至1.0
   - 强趋势时（>2.0）降低至0.3

2. **买入信号**条件：
   - 预期收益率 > 信号阈值
   - 5日均线 > 20日均线
   - RSI < 70（非超买）

3. **卖出信号**条件：
   - 预期收益率 < -信号阈值
   - 5日均线 < 20日均线
   - RSI > 30（非超卖）

4. **信号置信度**计算：
   ```python
   confidence = min(0.95, (trend_confidence * 0.4 + 
                        momentum_confidence * 0.4 +
                        rsi_confidence * 0.2))
   ```

### 2.2 回测信号生成（backtesting.py）

在`generate_signals`函数中：

1. **多时间框架动量**：
   - 1日、5日、10日、20日动量指标
   - 加权组合：1日(40%)、5日(30%)、10日(20%)、20日(10%)

2. **移动平均线**：5日、10日、20日

3. **趋势识别**：
   - 短期趋势：5日均线与10日均线比较
   - 长期趋势：10日均线与20日均线比较

4. **波动率调整阈值**：
   ```python
   vol_adjusted_threshold = threshold * (1 + signals['volatility'] * 5)
   ```

5. **买入信号**条件：
   - 动量信号 > 波动率调整阈值
   - 短期趋势为上升（1）
   - 价格高于5日均线
   - 价格位置 < 0.8（非过度超买）

6. **卖出信号**条件：
   - 动量信号 < -波动率调整阈值
   - 短期趋势为下降（-1）
   - 价格低于5日均线
   - 价格位置 > 0.2（非过度超卖）

7. **信号置信度**计算：
   ```python
   signals['confidence'] = (
       signals['trend_strength'] * 0.4 +
       signals['momentum_strength'] * 0.4 +
       (1 - signals['volatility'] * 5) * 0.2
   )
   ```

## 3. 参数优化机制

系统实现了自适应参数优化机制，主要在`parameter_optimizer.py`中：

### 3.1 默认参数

```python
{
    'lookback_window': 252,  # 默认1年
    'volatility_threshold': 0.2,
    'volume_threshold': 1.5,
    'momentum_window': 20,
    'prediction_horizon': 10,
    'backtest_split': 0.7,  # 70%训练，30%测试
}
```

### 3.2 参数优化逻辑

1. **优化频率**：默认每5个交易日优化一次

2. **基于市场条件的参数调整**：
   - **高波动率环境**（>0.3）：增加回溯窗口（最多3年）
   - **低波动率环境**（<0.15）：减少回溯窗口（最少6个月）
   - **强趋势环境**（>0.05）：增加预测周期（最多20天）
   - **弱趋势环境**：减少预测周期（最少5天）

3. **性能评分计算**：
   ```python
   performance_score = (
       metrics.get('sharpe_ratio', 0) * 0.4 +
       metrics.get('win_rate', 0) * 0.3 +
       (1 - abs(metrics.get('max_drawdown', 1))) * 0.3
   )
   ```

4. **版本管理**：系统保存参数历史版本，支持回滚到表现更好的历史版本

## 4. 技术指标库

系统在`indicators.py`中实现了丰富的技术指标：

1. **移动平均线**（MA）：简单移动平均
2. **指数移动平均线**（EMA）：基于指数加权
3. **相对强弱指数**（RSI）：默认14日周期
4. **布林带**（Bollinger Bands）：默认20日周期，2倍标准差
5. **MACD**：默认参数为12、26、9
6. **随机震荡指标**（Stochastic Oscillator）：默认K=14，D=3
7. **平均真实范围**（ATR）：默认14日周期
8. **能量潮指标**（OBV）：基于价格和成交量关系

## 5. 风险管理指标

系统计算多种风险管理指标：

1. **风险价值**（VaR）：在给定置信水平下的潜在损失
2. **条件风险价值**（CVaR）：超过VaR的平均损失
3. **最大回撤**：历史最大价格下跌幅度
4. **夏普比率**：超额收益与波动率的比值
5. **索提诺比率**：仅考虑下行风险的夏普比率变体
6. **卡玛比率**：年化收益与最大回撤的比值

## 6. 系统工作流程

1. **数据获取**：使用yfinance获取历史股票数据
2. **特征工程**：计算各种技术指标
3. **模型训练**：训练LightGBM或集成模型
4. **参数优化**：基于回测结果优化参数
5. **信号生成**：基于预测和技术指标生成交易信号
6. **性能评估**：计算夏普比率、最大回撤、胜率等指标
7. **结果存储**：使用MLflow跟踪实验结果

总结来说，该系统采用了多层次的技术分析和机器学习方法，结合动态参数优化，来预测股票价格走势并生成交易信号。系统的核心优势在于自适应参数调整和多指标集成决策，能够根据不同市场环境调整预测策略。
